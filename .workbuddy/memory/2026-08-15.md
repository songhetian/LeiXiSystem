## 雷犀管理系统 · UI 重塑（设计阶段，未改代码）

### 诊断（已对照真实代码）
- **跳转延迟根因 1（架构）**：`AppLayout` 是普通组件而非 Next `layout.tsx`，每个页面自行 `<AppLayout>` 包裹 → 每次路由切换整个壳子（侧边栏权限过滤、顶栏未读数拉取、Socket.IO 重连、ProtectedRoute）全量重挂载。
- **跳转延迟根因 2（体验）**：页面 `useEffect`+axios 挂载即拉数据 + 裸 spinner，无骨架屏/过渡/预取。
- **边距问题**：`PageContainer` 用 `maxWidth:1400px` 居中，但外层 `AppLayout` 内容区已 `padding:24`，宽屏下内容两侧留白与满宽顶栏脱节。
- **分页**：`ProTable` 用裸 Arco `Pagination` 默认样式，缺条数选择器/跳转器统一风格，且贴在表格底无卡片页脚包裹。
- **模块堆叠**：页面是 SearchForm 卡片 + toolbar Space + Table + ModalForm 硬堆，缺页面头部带与统一卡片容器。
