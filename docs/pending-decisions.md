## C 组 · 边界场景（已确认）

| # | 决策 |
|---|---|
| C1 | 跨天班次：班次支持"次日结束"标志，考勤按班次归属日期归集 |
| C2 | 月中入职/离职：按当月实际出勤天数折算；离职随最后考勤周期结算 |
| C3 | 同日多次打卡：早班取首次为上班卡、最后一次为下班卡；次数 > 4 标记异常待人工复核 |
| C4 | 补卡：走审批流，批准后人工写入考勤日报并留痕（补卡人/原因） |
| C5 | 加班：时长 = min(申请时长, 实际超出班次下班后的打卡时长) |
| C6 | 试算调整：新增 `payroll_adjustments` 表记录调整项（员工/项目/金额/原因/操作人），不直接改计算明细 |
| C7 | 发布撤回：已发布可撤回重算，仅限员工未查看状态；已查看走"补发/更正"流程 |
| C8 | **部门数据隔离**：列表/详情/报表按"可见部门范围"过滤（超管/HR 全量，部门经理本部门）→ ADR-0010 |
