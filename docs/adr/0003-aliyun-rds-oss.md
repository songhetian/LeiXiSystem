# ADR-0003: 生产环境使用阿里云 RDS + OSS

- 状态：已接受（Accepted）
- 日期：2026-08-12

## 背景

原"上线项目使用 res 和 oss"经确认实为**阿里云 RDS（云数据库 MySQL 8）+ 阿里云 OSS（对象存储）**。

## 决策

- 数据库（生产）：**阿里云 RDS（MySQL 8）**，Prisma 直连 RDS 连接串；本地开发连本地 MySQL，连接信息走环境变量。
- 对象存储：**阿里云 OSS**，继续用于头像、附件、知识库文件，前端直传或后端签名上传。
- Redis：仅本地开发/按需引入（token 缓存、打卡机同步状态等），不提前架构。

## 后果

- 正向：RDS 托管数据库免运维、自动备份；OSS 存储成本低、访问控制完善。
- 成本：生产与本地环境通过连接串区分，需规范 .env 管理；避免把生产凭据提交进代码库。
