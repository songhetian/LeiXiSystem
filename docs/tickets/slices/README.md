# 垂直切片 Tickets（tracer bullets）— 总览

> 来源：`/to-issues` 拆分 `docs/spec/technical-spec.md` + `docs/architecture.md`
> 原则：每个切片是**端到端垂直**（数据库→后端接口→业务算法→前端页面→单元测试 全贯穿），**可独立演示/验证**；不是按层水平拆分。
> 与 `step-*.md` 的关系：slices 是执行粒度（干活的），step 是阶段分组（验收的）。切片按依赖顺序完成即推进 step。
> 发布方式：本地 Markdown（docs/agents/issue-tracker.md）。
