# S07 · 考勤规则引擎 + 日报（核心曳光弹）

## What to build
**核心算法切片**：打卡流水 × 排班 → 考勤日报。规则引擎为 domain 纯函数（原型已验证，23 项断言），生产化实现并接入：定时重算日报、查询日报（异常标记）、单测回归基线。

## 五维清单
- **数据库**：attendance_daily（新表；uk(employee_id, work_date)；字段见 docs/schema/new-tables.md）
- **后端接口**：GET /attendance/daily（日期范围/员工/部门筛选，异常标记）、POST /attendance/daily/recalc（重算，供定时/手动）
- **业务算法**：**考勤规则引擎**（domain 纯函数，spec 2.2）：首次/末次打卡取值、>4 次异常、迟到/早退分钟、加班=min(申请,实际超时)（C5）、跨天班次归属（C1）、请假/补卡状态合并（S06/S09 数据）
- **前端页面**：考勤日报页（员工日报列表、异常高亮、详情展开）
- **单元测试**：**引擎单测 = 原型 11 用例回归基线**（prototypes/engine-demo.mjs 移植）+ API e2e

## Acceptance criteria
- [ ] 引擎生产实现，原型 11 用例全部 PASS
- [ ] 日报按员工+日期唯一，跨天/多次打卡/加班判定正确
- [ ] 日报页展示异常标记，重算按钮可用
- [ ] 引擎零框架依赖（可独立跑单测）
