# 雷犀系统项目开发标准 (Project Standards)

## UI 与视觉规范
- [2026-02-23] **Win11 蓝调风格**：全站核心 UI 采用亮蓝色渐变 (`#4FACFE` -> `#0052D4`)。
- [2026-02-23] **极致单行顶栏**：模块头部采用单行布局，高度压缩，背景使用 `bg-white/90 backdrop-blur-md` 增加通透感，并设为 `sticky top-0`。
- [2026-02-23] **图标系统**：全面使用 `Lucide-react` 矢量图标；文件夹和文档使用 SVG 渐变色区分状态。
- [2026-02-23] **下拉组件规范**：全站禁止使用原生 `<select>`。必须使用 AntD Select 或自定义封装组件，应用 `borderless` 样式和 `rounded-xl` 圆角。
- [2026-02-23] **弹窗组件规范**：全站禁止使用浏览器原生 `alert()`、`confirm()`。必须使用定制的 Win11 风格 Modal 或弹窗组件，确保视觉统一且不阻塞线程。
- [2026-02-23] **圆角规范**：统一采用 `rounded-xl` (12px) 或 `rounded-2xl` (16px)，保持商务干练。
- [2026-02-28] **全维度搜索标准**：管理类列表头部搜索区域必须执行“单行全铺满、自适应比例、高度 44px、边框 slate-500 (#64748b)”标准。
- [2026-02-28] **纤巧版分页标准**：全局统一使用极致紧凑的分页样式，Active 状态强制为黑底白字，移除笨重的背景衬底。
- [2026-02-28] **视觉对比度标准**：当按钮或背景色为黑色/深蓝色系时，文字颜色必须强制设为白色 (#FFFFFF)，严禁使用默认深灰色。

## 业务逻辑铁律
- [2026-03-02] **文件修改禁区**：严禁以任何理由（包括“优化”、“对齐 UI”、“简化逻辑”等）修改 `src/components/EmployeeManagement.jsx`。该页面必须保持 Ant Design 原始版本，任何变更必须由用户手动执行。
- [2026-02-23] **知识库三位一体逻辑**：公共库(Public)、管理中心(Management)、个人库(Personal) 严格按 type 和 owner_id 物理隔离。
- [2026-02-25] **逻辑收纳规范**：当页面存在大量重复相同业务框时，必须自动优化为 Tab 切换样式，以提升操作聚焦感。
- [2026-02-28] **云端存储简化原则**：阿里云 OSS 配置必须实现“RDS 化”。不准手动传递完整 Endpoint，后端应通过 Region、Bucket、Internal 标志位自动拼接连接路径。
- [2026-02-28] **业务分目录存储**：所有上传文件必须通过 `bizType` 参数实现按业务分类存储（如 /reimbursement/, /knowledge/），严禁文件堆放在根目录。
