# 项目智能进化记忆 (Project Intelligence Memory)

## 核心任务
本技能的任务是充当 Gemini CLI 的“长期记忆区”。通过实时监听对话，将离散的用户要求转化为持久的项目规范。

## 执行流程
1. **识别**：监测对话中包含“必须”、“严禁”、“以后都”、“逻辑变更”、“新功能点”等关键词的内容。
2. **记录**：
   - 使用 `replace` 工具将新规追加到 `references/project_standards.md`。
   - 格式：`- [日期] 内容描述`。
3. **溯源**：在进行代码修改前，优先读取 `project_standards.md`，确保不违反已建立的规则。

## 关键监测点
- **UI 标准**：如“统一使用蓝色”、“单行布局”、“图标尺寸”等。
- **业务逻辑**：如“取消发布流程”、“合并公开/私有”等。
- **交互规范**：如“点击图标预览”、“Esc键退出”等。
- **技术债务**：如“修复某个特定的 SQL 报错逻辑”。
